# nihilist-subtraction-practice
A training program to practice the quick execution of the subtraction involved in Nihilist Substitution ciphers.
## Use
- Enter the number that results when subtracting the given number by the given key. So, if your key is 15, and you see the number 68, you should enter `13`. Enter the number as an integer using numerals.
- Enter `KEY` to change the key number. Otherwise, it stays the same between repetitions.
- Enter `EXIT` to exit the program, and get a summary of your performance.
